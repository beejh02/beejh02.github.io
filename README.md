# 나의 책상

따뜻한 조명이 비치는 짙은 월넛 책상 위에 놓인, 내용 없는 3D 책입니다. React, TypeScript, Three.js, Vite로 구성했습니다.

책상 시점은 22도 화각으로 원근을 완만하게 표현합니다. 닫힌 책의 높이에 따른 수평 위치를 아주 조금 보정해 왼쪽 책등이 살짝 보이게 하고, 책을 펼치면 보정을 부드럽게 풀면서 읽기 시점의 28도 화각으로 전환합니다.

책상 위 비닐 레코드는 홈과 중앙 라벨을 코드로 생성합니다. 화면 위쪽에 걸쳐 배치해 윗부분이 화면 밖으로 잘리고 중앙 라벨은 보이도록 합니다. 소품 크기는 화면에 보이는 책 높이를 공통 기준으로 사용해 화면 비율이 바뀌어도 서로의 비율을 유지합니다. 책을 펼치면 전환이 끝난 뒤 레코드의 모델·재질·텍스처를 해제하고, 책상으로 돌아올 때 다시 생성합니다.

연필 자리에는 노란 육각 연필을 배치했습니다. 깎인 나무 끝, 흑연심, 금속 밴드와 분홍색 끝 지우개를 3D로 구성하고 책상에 그림자를 드리웁니다. 화면 크기에 맞춰 위치와 크기를 조정하며, 책을 펼치면 레코드와 함께 해제하고 돌아올 때 다시 생성합니다.

오른쪽 위에는 참고 이미지에 맞춘 회색 전면과 검은 테두리의 납작한 폴라로이드 즉석카메라를 배치했습니다. 전면 전체의 원근을 보정해 위아래 폭이 같고, 글자는 수평으로, 렌즈는 원형으로 보이도록 합니다. 높은 표면은 왼쪽으로 아주 조금 물러나도록 보정해 몸체와 렌즈의 오른쪽 측면이 살짝 드러납니다. 몸체 두께는 얇게 유지하면서 측면과 그림자로 입체감을 표현합니다. 중앙의 큰 렌즈, 왼쪽 뷰파인더와 빨간 버튼, 오른쪽 플래시, 아래쪽 무지개 스트라이프와 ‘경험’ 라벨을 구성했습니다. 모델과 라벨을 코드로 생성하며, 책을 펼치면 해제하고 책상으로 돌아오면 다시 생성합니다.

즉석카메라에 마우스를 올리면 아래 배출구에서 흰 테두리의 호수 사진이 부드럽게 나오고, 마우스를 빼면 다시 들어갑니다. hover 테두리는 카메라와 출력된 사진의 바깥 윤곽을 하나로 합쳐 그립니다. 접합부 안쪽에는 선을 그리지 않으며, 하나의 금빛 테두리가 출력과 복귀에 맞춰 밝아지고 잦아듭니다. 사진은 이전에 화면에 보이던 가로·세로 크기에서 7% 줄이고, 배출과 복귀 중에도 원근을 보정해 위아래 폭이 같은 직사각형을 유지합니다. 지우개는 사진이 나오는 자리를 피해 배치합니다. 사진 위로 이동해도 카메라 hover가 유지되지 않으며, 움직임 줄이기 설정에서는 사진 위치를 즉시 바꿉니다. 사진은 `public/images/polaroid-lake.jpg`를 사용하고 카메라와 함께 자원을 해제합니다.

오른쪽 여백에는 파란색과 아이보리색 종이 슬리브로 감싼 흰 지우개를 배치했습니다. 둥근 모서리, 인쇄 라벨과 접촉 그림자를 코드로 생성하며, 화면 비율에 맞춰 연필과 충분한 간격을 두고 놓습니다. 다른 소품처럼 책을 펼치면 해제하고 돌아오면 다시 생성합니다.

[The Book of Qbject](https://github.com/Qbject/the-book-of-qbject)의 책 곡면과 넘김 코드를 적용했습니다. 원본 글·그림·영상은 포함하지 않으며, 월넛·종이·천 표지 질감은 코드로 생성합니다. 라이선스는 [THIRD_PARTY_NOTICES.md](./THIRD_PARTY_NOTICES.md)에 있습니다.

## 조작

- 책상 화면에서 책, 레코드, 연필, 지우개, 폴라로이드에 마우스를 올리면 실제 윤곽을 따라 은은하게 빛나며 책상에서 살짝 들어 올려집니다. 마우스를 떼면 부드럽게 내려오고, 그림자는 책상 위에서 퍼지고 옅어집니다. 움직임 줄이기 설정에서는 애니메이션 없이 반응합니다. 레코드는 키보드 포커스에도 같은 효과가 나타나며, 클릭 영역은 내려놓은 위치와 들어 올린 위치를 함께 포함합니다.
- 레코드를 누르면 책상에서 보이던 레코드판이 프로젝트 화면(`#projects`)의 자리와 크기로 부드럽게 이동한 뒤 프로젝트 내용이 나타납니다. 도착한 레코드는 책상의 표면·라벨·그림자를 유지합니다. 아래로 스크롤하면 카드가 원호를 따라 위로 회전하면서 01 → 02 → 03 → 01 순서로 끝없이 전환됩니다. 위로 스크롤하면 역방향으로 돌아가며, 카드를 눌러 이동할 수도 있습니다. 카드와 레코드판이 같은 회전축을 공유합니다. `책상으로 돌아가기` 또는 `Esc`로 복귀할 수 있습니다.
- 닫힌 책을 클릭하면 표지가 펼쳐지면서 책 중심 화면으로 전환됩니다.
- 레코드가 프로젝트 화면으로 이동하는 동안 책·카메라·연필·지우개는 시간차를 두고 책상 밖으로 밀려나며, 배경과 프로젝트 내용이 부드럽게 이어집니다.
- 프로젝트에서 돌아오면 레코드판이 현재 회전 각도에서 책상 자리로 작아지며 이동하고, 책과 소품들도 역방향으로 들어옵니다. 돌아가기 버튼·`Esc`·브라우저 뒤로 가기에 같은 전환을 사용합니다.
- 프로젝트를 보는 동안 책상 3D 장면은 하나만 유지하고 렌더링과 책상 키보드 입력을 멈춥니다. 레코드 이동 이미지는 처음 만든 한 장을 재사용하며, 돌아갈 때는 현재 화면 크기에 맞는 위치만 계산해 복귀 애니메이션을 시작합니다. 반복해서 왕복해도 책상 장면이나 이동 이미지가 추가로 쌓이지 않습니다.
- 프로젝트 배경도 책상·책 화면과 같은 월넛 책상과 조명을 사용합니다. 소품이 빠져나간 뒤 기존 캔버스에 책상만 한 번 그리고 렌더링을 멈춰 배경으로 유지합니다. 창 크기가 바뀔 때만 배경을 다시 그리며, 별도 배경 이미지나 CSS 나무 무늬를 만들지 않습니다.
- 프로젝트의 레코드판 원형 표면을 잡아 끌면 회전축을 중심으로 손을 따라 돌아갑니다. 놓으면 가까운 프로젝트에 안착하고, 짧은 드래그나 취소는 원래 프로젝트로 돌아갑니다. 마우스·터치를 지원하며 스크롤과 카드 클릭도 사용할 수 있습니다. 카드와 빈 배경에서는 레코드 드래그가 시작되지 않습니다.
- 프로젝트 화면의 빈 책상 배경을 클릭하면 책상으로 돌아갑니다. 레코드판·카드·상세 내용·상단 메뉴를 클릭하거나 드래그·스크롤할 때는 돌아가지 않습니다.
- 책을 펼칠 때도 레코드·카메라·연필·지우개가 책상 밖으로 밀려나고, 책을 덮으면 반대 경로로 제자리에 돌아옵니다. 표지를 잡아 끌다 되돌리면 소품들도 함께 되돌아옵니다.
- 표지나 책장을 잡아 끌면 움직인 거리만큼 실시간으로 펼쳐지거나 휘어집니다. 오른쪽 책장은 왼쪽으로, 왼쪽 책장은 오른쪽으로 끌어 넘깁니다. 절반 이상 넘긴 뒤 놓으면 다음 쪽에 안착하고, 그 전에 놓으면 원래 자리로 돌아옵니다.
- 책 화면 오른쪽 위의 `책상으로 돌아가기` 버튼을 누르면 책이 닫히면서 책상 화면으로 돌아갑니다.
- 책을 펼친 화면의 빈 책상 배경을 클릭해도 책이 닫히면서 책상으로 돌아갑니다. 책장 클릭과 드래그는 기존처럼 책장을 넘기며, 배경을 끌거나 책장을 잡은 채 배경에서 놓아도 복귀하지 않습니다.
- 오른쪽 책장 클릭 또는 `→`: 다음 책장
- 왼쪽 책장 클릭 또는 `←`: 이전 책장
- `Esc`: 책을 덮고 처음 책상 화면으로 돌아가기
- 모바일: 책장 터치 또는 손가락으로 잡아 좌우로 끌기
- 움직임 줄이기 설정에서는 드래그 위치를 바로 반영하고, 클릭 이동과 드래그를 놓은 뒤의 정착 애니메이션을 생략합니다.

## 수정 위치

- `src/App.tsx`: 책상·프로젝트 화면과 이동 중인 레코드 이미지 구성
- `src/navigation/useRecordNavigation.ts`: 책상 / 프로젝트 전환 상태, 주소 변경과 포커스 복원
- `src/navigation/recordTransition.ts`: 레코드 위치 측정과 이동 애니메이션, 프레임·스타일 정리
- `src/Desk.tsx`: 책상 화면과 책상으로 돌아가기 버튼
- `src/projects/ProjectsPage.tsx`: 프로젝트 카드와 상세 영역
- `src/projects/useProjectWheel.ts`: 프로젝트 휠의 스크롤 반복, 드래그·선택, 화면 크기 변경과 이벤트 정리
- `src/projects/wheelGeometry.ts`: 카드·레코드·드래그가 공유하는 프로젝트 회전 간격
- `src/projects/projects.ts`: 프로젝트 정보·이미지·사이트 및 GitHub 링크 입력
- `src/projects/projects.css`: 프로젝트 페이지 스타일
- `src/study/scene.ts`: 책상·조명 설정, 렌더링과 모듈 연결
- `src/study/Book.ts`: 책 모델 조립, 책장 곡면·위치와 hover 효과
- `src/study/BookController.ts`: 책장 진행 상태, 드래그·키보드 입력과 정착 애니메이션
- `src/study/RecordCapture.ts`: 레코드 이미지 캡처·재사용과 현재 책상 위치 측정
- `src/study/Resources.ts`: 캔버스 텍스처 생성과 모델별 GPU 자원 해제
- `src/study/types.ts`: 책 상태와 책상 장면의 공통 인터페이스
- `src/study/DeskInteractions.ts`: 오브젝트별 hover 상태, 들어 올리는 효과, 외곽선과 클릭 영역
- `src/study/ScreenContours.ts`: 화면에 투영한 윤곽 계산과 윤곽 내부·가장자리 판정
- `src/study/DeskProps.ts`: 소품 등록, 생성·표시·제거와 자원 해제
- `src/study/DeskLayout.ts`: 책상·책 카메라, 반응형 소품 배치와 폴라로이드 원근 보정
- `src/study/DeskClearance.ts`: 책·레코드 전환에 공통으로 쓰는 소품 이동 경로, 시간차, 회전과 원위치 복원. 이동 방향과 속도는 이 파일의 `motions`와 `motionDuration`에서 조정합니다.
- `src/study/Page.ts`: 종이 곡면과 넘김
- `src/study/Record.ts`: 비닐 레코드 모델과 질감
- `src/study/Pencil.ts`: 연필 모델과 질감
- `src/study/Eraser.ts`: 지우개 모델, 종이 슬리브와 그림자
- `src/study/Polaroid.ts`: 폴라로이드 즉석카메라 모델과 그림자
- `src/study/materials.ts`: 월넛·종이·표지 질감
- `src/style.css`: 화면 배치와 반응형 스타일
